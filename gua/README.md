# 薛定谔的卦 · 中国算命 × 量子力学

150 秒竖屏（1080×1920，30 fps）。画风“鎏金线刻 · 古籍星图”：墨色星空、二十八宿星图、金色线刻、朱砂印。
画面全部由代码逐帧绘制（罗盘、开元通宝、四柱八字、五行生克、六爻与六十四卦、浑天仪式布洛赫球、天眼）；
配乐原创合成（古琴、箫、筝、鼓、钟，量子段落加轻电子律动），无采样。顶部是章节进度条：引｜八字｜起卦｜叠加｜坍塌｜测量｜天命？｜结语。

## 内容要点
- 八字：年月日时各配一干一支 → 四柱八字 → 五行生克。
- 《周易》起卦：三枚铜钱掷六次，自下而上成六爻；2⁶ = 64 卦；莱布尼茨 1703 年的二进制论文提到伏羲卦序。
- 量子比特 ↔ 爻：叠加态 ≠ “还不知道”（双缝干涉为证）；测量后坍塌（注明这是哥本哈根诠释的说法）。
- 测量不需要人看：环境相互作用导致退相干（布洛赫矢量缩短）；宏观物体早被环境“测量”无数次。
- 经典决定论（拉普拉斯，1814）与量子概率；量子随机数。
- 算命“准”的原因：巴纳姆效应、自证预言。结尾：乾卦象传“天行健，君子以自强不息”。

## 运行
```
node tools/audio.mjs      # → assets/soundtrack.m4a
node tools/render.mjs     # → dist/xuedinge-de-gua.mp4
```
需要 Node + Playwright（Chromium）、ffmpeg；字体 Noto Serif SC 与马善政楷书（SIL OFL，@fontsource）放在 fonts/files。
