# 薛定谔的签 · 算命 × 量子力学

150 秒竖屏知识短片（1080×1920，30 fps），霓虹贴纸风：深紫底、彩虹极光、粗描边贴纸、动态大字幕。
画面全部是代码逐帧绘制的原创图形；配乐是原创合成（96 BPM，D 小调，国风电子：筝、笛、鼓组、贝斯、锣），无采样。

## 科学上的分寸
- “坍塌”是哥本哈根诠释的说法，画面上有注明；多世界诠释里没有坍塌。
- 物理里的“测量”是与环境的相互作用（退相干），不需要“有人在看”。
- 量子力学给的是概率；拉普拉斯式的决定论属于经典物理。
- 巴纳姆效应、自证预言是心理学/社会学概念，不是量子效应——片子正是用它们收尾。
