# 从俳句到神话 · FROM HAIKU TO MYTHOS

*The Poetry Behind Claude’s Names* — 一部 150 秒、9:16 竖屏的微型艺术短片。
画面、配乐、拟音全部由本仓库的代码生成：没有外链素材，没有采样，没有录音。

| 成品 | 路径 | 说明 |
| --- | --- | --- |
| 成片 MP4 | `dist/from-haiku-to-mythos.mp4` | 1080 × 1920 · 30 fps · H.264 High + AAC 48 kHz 立体声 · 150.000 s |
| 单文件播放版 | `dist/from-haiku-to-mythos.html` | 代码 + 字体 + 配乐全部内嵌，可直接在 iPhone Safari 打开 |
| 工程版 | `index.html` + `src/` + `assets/` | 本地起一个静态服务器即可运行 |
| 旁白时间码 | `docs/narration.srt` / `.vtt` / `.json` | 与字幕同源的配音稿与精确时间标记 |

## 运行

```bash
npx serve .            # 或任意静态服务器，然后打开 index.html
# 单文件版无需服务器：直接打开 dist/from-haiku-to-mythos.html
```

播放器：开始（iOS 音频解锁）/ 暂停 / 继续 / 重播 / 进度拖动 / 静音 / 音量 / 高·中·低三档画质 / 全屏（设备支持时）。
快捷键：空格 播放暂停，← → 跳 5 秒，M 静音，F 全屏，R 重播。
画面、字幕、配乐共用一个主时钟（Web Audio 的音频时钟）；`F.render(ctx, t)` 是时间 `t` 的纯函数，所以拖动、暂停、离线渲染得到的是同一帧。

## 重新生成

```bash
python3 tools/build-fonts.py <Noto Serif SC woff2 目录>   # 字体子集（只含片中出现的字）
node tools/audio.mjs --stems     # 合成配乐 → build/soundtrack.wav、分轨、assets/audio/soundtrack.m4a
node tools/render.mjs            # 无头 Chromium 逐帧渲染 4500 帧 → dist/*.mp4
node tools/build.mjs             # 单文件版 + 旁白时间码
node tools/still.mjs 27 86 135   # 任意时刻的检查截帧 / 联系表
node tools/playtest.mjs          # 在 iPhone 视口里对播放器做冒烟测试
```

## 结构（150 秒，一条时间轴）

| 时间 | 幕 | 画面因果 | 配乐（同一个五音动机 A–B–D–E–B → D） |
| --- | --- | --- | --- |
| 0:00–0:12 | 序章 | 金点 → 纸纤维 → 金线边框 → 墨滴化为第一个字母 | 动机被一个音一个音地找到（毡钢琴 + 磬） |
| 0:12–0:38 | Haiku | 和纸展开 → 墨竹 → 金月 → 墨迹化山与倒影 → 一叶入水 | 十七个音，五—七—五（筝 / 磬 / 风） |
| 0:38–1:06 | Sonnet | 涟漪成圆章 → 玫瑰 → 十四条金线 → 金线旋转成五线谱 | 3/4，十四小节 = 十四行（4+4+3+3），竖琴、弦乐四重奏、钢琴 |
| 1:06–1:34 | Opus | 谱线成阶梯，音符落成柱础 → 列柱升起 → 山花、晨光 | 动机增值，圆号 → 弦乐八度，全片唯一一次宏大高潮 |
| 1:34–1:59 | Fable | 山花浮雕里的狐与鸦 → 书页 → 纸雕剧场 | 6/8，单簧管讲述，音乐盒倾听，借用和弦带来奇境 |
| 1:59–2:22 | Mythos | 狐仰望，星连成座 → 星图、缪斯像、桂冠 | D 利底亚，动机被“唱”出来（合成女声吟唱 + 管风琴 + 弦乐） |
| 2:22–2:30 | 尾声 | 星图回到纸上成为花环，五个名字汇聚，边框开花 | 动机回到一根拨弦，终于落在主音；自然收束 |

图层：L0 纸 · L1 远景/光 · L2 中景 · L3 主体 · L4 近景视差 · L5 文字（永远在最上，绝不被遮挡）· L6 金箔与柔光 · L7 转场遮罩。

## 三种信息，分开说

片中每条信息都带着出处的“身份”：

- **词源**（标注 `ETYMOLOGY 词源`）：俳句（日语 haiku，五—七—五，十七音）；sonnet ← 意大利语 *sonetto*“小歌”← 拉丁语 *sonus*；*opus* 拉丁语“作品、劳作”，复数 *opera*；fable ← 拉丁语 *fābula*“被讲述的事”← *fārī*“言说”；mythos ← 希腊语 μῦθος“言说、故事”。
- **产品事实**（标注 `ANTHROPIC 产品事实`）：Haiku / Sonnet / Opus 的定位；Fable 5.2 是目前公开可用的最智能模型；**Mythos 5.2 与 Fable 5.2 共享同一底层模型，区别在于安全防护与访问条件**——不是两个能力等级。
- **诗意联想**（旁白与字幕，不加标注）：本片自己的文学想象，并非官方命名释义。片尾用小字再次声明。

## 关于声音：如实说明

- **配乐与拟音是真实音轨**：`src/score.js` 用纯算术合成（Karplus–Strong 拨弦、加法合成钢琴与钟磬、波表弦乐/木管/圆号/管风琴、FFT 卷积混响、前视限幅），48 kHz 立体声。成片整体响度约 −15.7 LUFS，真峰值 −1.5 dBFS。
- **“女声吟唱”是共振峰合成的人声音色**，不是真人女高音的录音。它是克制的、合唱垫底式的质感；若需要真人演唱，分轨 `stem-vocal` 可以被直接替换。
- **中文旁白没有随片附带人声**。当前环境没有达到电影级的中文配音合成或录音条件，所以没有用机器音冒充成品；片中以与旁白逐句同步的字幕呈现全文。接口已经留好：
  - 把配好的旁白（整条、从 0 秒对齐、任意常见格式）放到 `assets/audio/narration.m4a|mp3|wav`，播放器会自动载入；或在播放器控制条里点「导入旁白音轨」。
  - 一旦有旁白，配乐会在每句旁白下自动让出 7 dB（时间取自同一张 cue 表）。
  - 渲染 MP4 时：`node tools/render.mjs --narration path/to/narration.wav`（侧链压缩让位后混合）。
  - 配音稿、时间码与声线说明见 `docs/NARRATION.md`。
