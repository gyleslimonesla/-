# 旁白配音稿 · 时间码 · 声线说明

本片随附的是**字幕版**：下列每一句都以字幕形式与画面精确同步，但没有附带人声。
时间码与片中字幕来自同一张表（`src/script.js` → `NARRATION`），机器可读版本见 `narration.srt` / `narration.vtt` / `narration.json`。

## 声线

- 成年女性，清澈、温柔、有书卷气；像在安静的阅览室里读给一个人听。
- 语速舒缓，约每秒 3.5–4 字；句内的逗号是真的停顿，破折号处略作悬停。
- 不播音腔，不撒娇，不模仿动画角色；情绪曲线跟随配乐：安静 → 温柔 → 庄重 → 亲密 → 神圣 → 平静。
- 外文词按原文读：*sonetto*（意）、*Opus* / *magnum opus*（拉丁）、*fabula*（拉丁）、*Mythos* / μῦθος（mŷthos，希腊）。

## 交付规格

- 整条干声，从 00:00.000 对齐，时长 ≤ 150 s；48 kHz，单声道或立体声，WAV 或 M4A。
- 峰值不超过 −3 dBFS，不要加混响（片中会统一处理空间感）。
- 放到 `assets/audio/narration.wav`（或 `.m4a` / `.mp3`）即被播放器自动载入；配乐在每句下自动让出 7 dB。
