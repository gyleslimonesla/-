# 落花雨 · 剪纸卡点短片

25.4 秒，1920×1080，30 fps。画风取参考视频的剪纸叠层：靛蓝、米白、金、朱红，纸片带投影、边缘受光、纤维纹理；
所有画面都是代码逐帧绘制的原创图形（没有使用参考视频的任何素材）。

## 卡点从哪来
`src/timing.js` 里的数字全部由歌曲本身测得（librosa 节拍/起音检测）：约 73 BPM，一拍 ≈ 0.82 s，四拍一小节，共 8 小节。
每个小节线切一个场景（闪白 + 镜头回弹），小节内的动作落在拍点上：

| 小节 | 时间 | 场景 | 拍点上的动作 |
|---|---|---|---|
| 1 | 0.07 | 月窗 | 梅枝花苞按拍点依次绽开；标题「落 / 花 / 雨」逐拍出字，第四拍落印 |
| 2 | 3.34 | 伞开 | 油纸伞每拍展开四分之一 |
| 3 | 6.73 | 桥 | 撑伞人过拱桥，每拍一阵风，花瓣成片飘 |
| 4 | 10.03 | 落水 | 每拍一片花瓣落入池中激起涟漪（12.47、12.91 两个重音涟漪更大），两尾锦鲤绕游 |
| 5 | 13.31 | 风起 | 月洞门里花瓣越旋越紧，在全曲最强重音 15.72 s 炸开 |
| 6 | 16.58 | 月下舟 | 长音段：大月、海浪、小舟；17.44 / 19.09 重音灯笼一亮 |
| 7 | 19.92 | 四拍 | 一拍一切：花开、风铃、旋伞、撑伞背影 |
| 8 | 23.13 | 落 | 回到月窗，梅花分三拍落尽，收于标题 |

## 歌词
参考视频的竖排逐字歌词是这类片子的灵魂，但本片**没有加歌词**：这个环境里没有可用的语音识别模型，
而凭记忆写歌词很可能写错。歌词轨已经留好：在 `TIMING.LYRICS` 里按
`[开始秒, 结束秒, '这一句', [要标红的字序号]]` 填入，重新渲染即可（约 20 秒）。
字会在开始到结束之间逐字浮现，竖排在画面右侧。

## 运行
```
# 依赖：Node + Playwright（Chromium）、ffmpeg；字体 Noto Serif SC 700/900 放在 fonts/files（@fontsource/noto-serif-sc）
cp 你的音频 assets/song.m4a
node tools/still.mjs --q .5 --cols 5 --scale .4 --out sheet.png 0:25:1   # 静帧联系表
node tools/render.mjs                                                   # → dist/luohua-yu.mp4
```
`index.html` 可在浏览器里边放音乐边实时预览。
