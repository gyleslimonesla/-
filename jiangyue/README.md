# 江月何年

一昼夜，六首诗。180 秒，9:16 竖屏。画面、配乐、拟音全部由本目录的代码生成，没有外部素材、采样或录音。

| 成品 | 路径 |
| --- | --- |
| 成片 | `dist/jiangyue-henian.mp4`（1080×1920 · 30 fps · H.264 + AAC 48 kHz · 180.000 s） |
| 单文件播放版 | `dist/jiangyue-henian.html`（代码、字体、配乐全部内嵌） |
| 工程版 | `index.html` + `src/` + `assets/` |
| 文稿时间码 | `docs/narration.srt` / `.vtt` / `.json` |

## 相对原始提案，改了什么

- **片名**：《诗中有山河》→《江月何年》。取自张若虚“江畔何人初见月，江月何年初照人”——一千三百年前的一问，片尾作答：“今夜，照你。”
- **骨架**：不再是六首诗的并列，而是**一昼夜**。从一个黄昏的月出，走到下一个黄昏的灯火；每章钤一方时辰印。

| 时辰 | 诗 | 画法 |
| --- | --- | --- |
| 黄昏 | 张若虚《春江花月夜》 | 银蓝夜色，近枝工笔花逐瓣开 |
| 人定 | 王维《山居秋暝》 | 立轴水墨，点墨成山，留白为月 |
| 夜半 | 张继《枫桥夜泊》 | 深蓝冷灰，枫红与渔火，三声钟 |
| 日出 | 李白《早发白帝城》 | 青绿山水勾金，群峰横移 |
| 日中 | 苏轼《饮湖上初晴后雨》 | 淡彩，先晴后雨，荷由苞而放 |
| 日入 | 王勃“落霞与孤鹜齐飞” | 一段过门，水天化为一色 |
| 黄昏 | 辛弃疾《青玉案·元夕》 | 灯树、城楼、烟火；然后退到灯火阑珊处 |

- **月亮是线索**：月出、月上、月落，日出日落之后，元夕又是满月；最后它成为纸上的一块留白。
- **每章开卷**：先是一幅绢本水墨“古画”（行书题款、朱印），像画帘一样自中缝拉开，露出设色、会动的同一方天地。
- **字**：诗句与题名用行书（志莽行书），导语与落款用思源宋体。
- **五种船**：扁舟（春江）、竹筏渔翁（山居）、乌篷客船（枫桥）、张帆轻舟（白帝）、朱栏画舫（西湖）。

## 运行与重新生成

```bash
npx serve .                      # 工程版；单文件版直接打开即可
python3 tools/build-fonts.py <node_modules>   # 字体子集
node tools/audio.mjs --stems     # 合成配乐与分轨
node tools/render.mjs            # 逐帧渲染 → MP4
node tools/build.mjs             # 单文件版 + 时间码
node tools/still.mjs 23 100 150  # 任意时刻截帧
node tools/playtest.mjs          # 播放器冒烟测试
```

`F.render(ctx, t)` 是时间的纯函数：拖动、暂停、离线渲染得到同一帧。播放器以 Web Audio 时钟为主时钟。

## 声音：如实说明

- 配乐与拟音是真实音轨（`src/score.js`，48 kHz 立体声）。一条五声“月”主题贯穿全片：箫（春江）→ 古琴（山居）→ 埙与三声钟（枫桥）→ 笛、琵琶、鼓（白帝）→ 二胡、筝（西湖）→ 箫（落霞）→ 合奏与烟火（元夕）→ 回到古琴（跋）。
- 这些“乐器”都是**合成音色**（拨弦模型、波表、加法合成），是对古琴、箫、筝、琵琶、埙、编钟的模拟，不是真乐器录音。片尾极轻的吟唱同样是合成人声音色。
- **没有旁白人声**。文案以竖排字幕呈现；若要配音，把整条旁白放到 `assets/audio/narration.wav|m4a|mp3`（从 0 秒对齐），播放器自动载入并让配乐让位，渲染时用 `--narration`。
